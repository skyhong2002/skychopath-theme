## 不是主題問題，未修改

以下項目屬於 Ghost 核心行為或後台資料。本次任務不修改 Ghost 資料，所以只記錄下來，由站長決定是否處理。

- **網站標題拼錯**：後台 Settings → General 的 Title 是「Skychoapth.」，與首頁 title 和 Logo 使用的「Skychopath.」不同。這個錯字出現在 `og:site_name`、首頁 `og:title`/`twitter:title`、JSON-LD publisher、RSS 標題，以及標籤、作者與分頁的 `<title>`（例如「Articles - Skychoapth.」）。
- **語系**：後台 Publication language 是 `en`，所以 `<html lang="en">`，Portal 和 Search 也使用英文。大多數內容是繁體中文，若改成 `zh-Hant` 或 `zh-TW`，Source 的介面字串也會跟著改變。
- **Sitemap 出現 `/home/`（301）且 `/` 重複**：這是 Ghost 在 `routes.yaml` 以 `data: page.home` 綁定首頁時的內建行為。`/home/` 在 GSC 會顯示為「Page with redirect」，屬於正常情況。
- **23 個 Sitemap 網址沒有 `<meta name="description">`**：Ghost 核心（`core/frontend/meta/description.js`）只會用文章的 meta description 或自訂摘要，以及作者頁的作者簡介產生這個標籤；`og:description` 則會自動從摘要補上。如需補上，請在後台逐篇填寫，作者頁則填寫作者簡介：`/2021-fall-recap/ /5-years-after-ai/ /about/ /author/sky/ /charm-based-motivation/ /community-cultivation/ /ddff-review/ /ffvii-rebirth-music-engineering/ /how-to-jam-your-data/ /i-do-backlog/ /ip-rights/ /letter-from-derek-sivers/ /llm-micro-course/ /now-20250511/ /now-20250609/ /now-20250731/ /now-20250831/ /now-20251130/ /recall-2025/ /relationship-meme/ /reminder-to-write-about/ /super-human-development-some-word/ /why-write-blog/`
- `/llm-micro-course/` 的內文有第二個 H1。
- 首頁內文連到 `/about`、`/guestbook`、`/rss`、`/now` 時沒有結尾斜線，每次都會多一次 301。
